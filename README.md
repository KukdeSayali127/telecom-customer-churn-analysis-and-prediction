# 📊 AI-Powered Telecom Customer Churn Analysis & Prediction

**Python • Machine Learning • Power BI**

An end-to-end Data Analytics and Machine Learning project that analyzes telecom customer behavior and predicts customer churn using the IBM Telco Customer Churn dataset.

---

## 📌 Project Overview

This project focuses on identifying customers who are likely to leave a telecom company by analyzing customer demographics, services, contracts, and monthly charges.

The project includes:

* 📈 Customer Churn Analysis Dashboard (Power BI)
* 🤖 Machine Learning Prediction Dashboard (Power BI)
* 🐍 Data Cleaning & Machine Learning using Python
* 📊 Business Insights for Customer Retention
